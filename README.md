# Bot Facebook - Painel Manychat Style

1. Suba tudo pro GitHub
2. No Railway, configure Variables:
   - FB_APP_ID
   - FB_APP_SECRET
   - REDIRECT_URI = https://SEU-APP.up.railway.app/auth/facebook/callback
   - VERIFY_TOKEN = meu_token_secreto_123
   - PAGE_ACCESS_TOKEN = (opcional, será preenchido automatico após login)

3. No Facebook Developers > Facebook Login > Settings:
   Valid OAuth Redirect URIs = https://SEU-APP.up.railway.app/auth/facebook/callback

4. Acesse https://SEU-APP.up.railway.app/ e clique em Logar com Facebook

Pronto!
